# Third-party references

`moon-wit` contains no vendored third-party source code or generated code from
third-party WIT packages.

The design and compatibility work reference these public projects:

| Project | Purpose | License |
| --- | --- | --- |
| `bytecodealliance/wit-bindgen` | Binding-generator architecture reference | Apache-2.0 with LLVM exception |
| `WebAssembly/component-model` | WIT and Component Model specification | Apache-2.0 with LLVM exception |
| `WebAssembly/wasi-io` | Real-world WIT syntax compatibility review | Apache-2.0 with LLVM exception |

Project fixtures are original minimal inputs. They reproduce language forms,
not upstream source text.
